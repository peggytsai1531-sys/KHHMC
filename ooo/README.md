# OOO 歷史報表

每日 T114 Out of Order 報表的分析結果，依月份存放。

- `history/YYYY-MM/YYYY-MM-DD_rooms.csv`：當日已生效 OOO 房號明細（房號、房型、理由分類、期間、備註）
- `history/YYYY-MM/YYYY-MM-DD_diff.csv`：與前一日差異（新增、解除、持續、連續天數）
- `history/YYYY-MM/YYYY-MM-DD.json`：當日完整解析結果
- `history/YYYY-MM/summary.csv`：當月每日摘要（OOO 總計、新增、解除、各理由分類房數）
- Excel 可隨時由上述 CSV 匯出。
